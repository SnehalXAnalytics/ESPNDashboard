# 📊 Cricket Player Performance Dashboard (ESPN Data)
Analysis of cricket player's performance with data sourced from ESPN.

# 📊 Overview

This Power BI dashboard provides an interactive analysis of cricket player performances across three major aspects of the game — Batting, Bowling, and Fielding.
The dataset is sourced from ESPN Cricinfo, transformed using Power Query, and visualized with a clean, minimal, and consistent design theme.

# 🧠 Purpose

The project aims to help users:

Analyze player performance trends across different match spans.

Compare batting, bowling, and fielding efficiency for any selected player.

Gain insights into individual strengths, consistency, and contribution.


# 📁 Dashboard Pages
## 🏏 Batting Analysis

Displays overall batting performance for each player.

**Key Metrics:**

Highest Score, Strike Rate, Average, Runs, Innings, Matches

Count of 100s, 50s, and 0s (ducks)

Includes filters for Player, Rank, and Span (Years) for dynamic exploration.

## 🧤 Fielding Analysis

Focuses on player involvement and effectiveness in the field.

**Key Metrics:**

Catches, Run-outs, Dismissals, Stumpings, Match Count

Distinction between Catches as Fielder and Catches as Wicket-keeper

Gives a complete view of fielding contribution to team performance.
